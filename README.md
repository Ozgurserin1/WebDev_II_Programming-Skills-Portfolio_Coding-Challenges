## About

This folder has my three C++ challenges for the Programming Skills Portfolio.

## Challenge 1 - CO2 Calculator

This program asks the user for the distance travelled and the fuel type. It then calculates the estimated CO2 amount.

The program uses:

- Functions
- User input
- If statements
- Input checking

## Challenge 2 - Alexa Joke

This program reads jokes from `randomJokes.txt`. The user types `Alexa, tell me a joke` and the program shows a random joke. The user can type `quit` to stop the program.

The program uses:

- File handling
- A struct
- A vector
- Random numbers
- A loop

Keep `randomJokes.txt` in the same folder as `main.cpp`.

## Challenge 3 - Book Manager

This program is used to manage books. The user can view books, borrow a book and return a book. The book information is read from `bookData.txt` and changes are saved when the program closes.

The program uses:

- A class and objects
- File handling
- A vector
- Functions
- A menu

Keep `bookData.txt` in the same folder as `main.cpp`.

## How to Run

Open one challenge folder in Visual Studio Code. Open the terminal and compile the program:

```bash
g++ main.cpp -o main
```

Run it on Windows:

```powershell
.\main.exe
```

Each challenge also has a compiled `main.exe` file inside the `output` folder.
